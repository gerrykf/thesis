## 前端上传代码示例

### Vue 3 前端实现

```typescript
// 方法1: 使用FormData（推荐）
async function uploadAvatar(file: File) {
  const formData = new FormData()
  formData.append('avatar', file) // ⚠️ 字段名必须是 'avatar'

  try {
    const response = await fetch('http://localhost:3000/api/auth/avatar', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}` // 需要携带token
        // ⚠️ 不要设置 'Content-Type'，让浏览器自动设置为 multipart/form-data
      },
      body: formData
    })

    const data = await response.json()
    if (data.success) {
      console.log('上传成功:', data.data.avatarUrl)
      // 返回的URL: /uploads/avatars/67_1761580454997.png
    }
  } catch (error) {
    console.error('上传失败:', error)
  }
}
```

### 使用Vant上传组件

```vue
<template>
  <van-uploader
    v-model="fileList"
    :after-read="afterRead"
    :max-count="1"
    accept="image/*"
  />
</template>

<script setup>
import { ref } from 'vue'
import { showToast, showLoadingToast, closeToast } from 'vant'
import { postAuthAvatar } from '@/api/auth'

const fileList = ref([])

async function afterRead(file) {
  showLoadingToast({ message: '上传中...', forbidClick: true, duration: 0 })

  const formData = new FormData()
  formData.append('avatar', file.file) // file.file 是原始File对象

  try {
    const response = await postAuthAvatar(formData)

    closeToast()
    showToast({ message: '上传成功', icon: 'success' })

    // 更新用户头像URL
    userStore.setUserInfo({
      ...userStore.userInfo,
      avatar: response.data.avatarUrl
    })
  } catch (error) {
    closeToast()
    showToast({ message: error.message || '上传失败', icon: 'fail' })
  }
}
</script>
```

## 后端API接口说明

### 接口地址
```
POST http://localhost:3000/api/auth/avatar
```

### 请求Headers
```
Authorization: Bearer <your-token>
Content-Type: multipart/form-data (浏览器自动设置)
```

### 请求Body (FormData)
```
avatar: <File对象>
```

### 支持的文件格式
- `image/jpeg` (.jpg, .jpeg)
- `image/png` (.png)
- `image/gif` (.gif)
- `image/webp` (.webp)

### 文件大小限制
- 最大 5MB

### 成功响应 (200)
```json
{
  "success": true,
  "message": "头像上传成功",
  "data": {
    "avatarUrl": "/uploads/avatars/67_1761580454997.png"
  }
}
```

### 错误响应

#### 400 - 未上传文件
```json
{
  "success": false,
  "message": "请上传头像文件"
}
```

#### 400 - 文件类型不支持
```json
{
  "success": false,
  "message": "只支持上传图片文件 (jpg, jpeg, png, gif, webp)"
}
```

#### 401 - 未授权
```json
{
  "success": false,
  "message": "未授权，请先登录"
}
```

## 常见问题排查

### Q1: 返回 "请上传头像文件"
**原因**: FormData字段名不是 `avatar`
**解决**: 确保使用 `formData.append('avatar', file)`

### Q2: 返回 404 访问图片
**原因**: 静态文件路径配置错误
**解决**: 已修复，确保服务器日志显示正确的静态文件目录

### Q3: 返回 "只支持上传图片文件"
**原因**: 文件MIME类型不是图片
**解决**: 只上传jpg/png/gif/webp格式的图片

### Q4: 返回 401 未授权
**原因**: 未携带token或token过期
**解决**: 在请求头添加 `Authorization: Bearer <token>`

## 旧头像自动删除机制

上传新头像时，会自动删除旧头像文件（如果存在）：

```typescript
// src/controllers/authController.ts:986-992
if (oldAvatar && oldAvatar.startsWith("/uploads/avatars/")) {
  const oldAvatarPath = path.join(__dirname, "../../", oldAvatar);
  if (fs.existsSync(oldAvatarPath)) {
    fs.unlinkSync(oldAvatarPath);
    console.log('[Upload] 删除旧头像:', oldAvatarPath);
  }
}
```

**注意**: 不会删除默认头像或外部URL头像
