📦 PWA 图标文件说明

请将以下文件放入当前目录（public/）：

必需文件：
-----------
1. pwa-icon-192.png
   - 尺寸：192 x 192 像素
   - 格式：PNG
   - 用途：主屏幕图标、应用切换器

2. pwa-icon-512.png
   - 尺寸：512 x 512 像素
   - 格式：PNG
   - 用途：启动画面、高分辨率显示

可选文件：
-----------
3. screenshot-1.png
   - 尺寸：540 x 720 像素
   - 格式：PNG
   - 用途：应用商店预览图

图标设计要求：
-------------
✓ 简洁明了，易于识别
✓ 使用应用主题色：#1989fa（科技蓝）
✓ 透明背景 或 纯色背景
✓ 重要内容保持在中心 80% 区域内（maskable 要求）

当前使用的是 PwaInstallPrompt.vue 组件中的内联 SVG 占位图标。
