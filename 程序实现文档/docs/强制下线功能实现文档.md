# 强制下线功能实现文档

## 一、功能概述

管理员可以在"系统监控 → 在线用户"页面强制任意在线用户下线，被强退用户会立即或在30秒内被踢出系统。

## 二、数据库设计

### 2.1 Token黑名单表

```sql
CREATE TABLE `token_blacklist` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `token` VARCHAR(500) NOT NULL,
  `user_id` INT NOT NULL,
  `reason` VARCHAR(200) DEFAULT '强制下线',
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  `expires_at` TIMESTAMP NOT NULL,
  INDEX `idx_token` (`token`(255)),
  INDEX `idx_user_id` (`user_id`),
  INDEX `idx_expires_at` (`expires_at`)
);
```

### 2.2 在线用户表更新

```sql
ALTER TABLE `online_users`
ADD COLUMN `token` VARCHAR(500) NOT NULL AFTER `username`,
ADD UNIQUE INDEX `idx_token` (`token`(255));
```

export const forceOfflineUser = async (req, res) => {
  const { id } = req.params;

  // 1. 查询在线用户获取token
  const [rows] = await db.execute(

  // 2. 将token加入黑名单
  await db.execute(
    `INSERT INTO token_blacklist (token, user_id, reason, expires_at)
     VALUES (?, ?, '管理员强制下线', ?)`,
    [onlineUser.token, onlineUser.user_id, onlineUser.expires_at]
  );

## 四、前端实现

### 4.1 心跳检测机制

**文件**: `src/utils/heartbeat.ts`

**功能**: 每30秒检查一次在线状态

```typescript
async function checkOnlineStatus() {
  const response = await fetch("/api/auth/profile", {
    headers: { Authorization: `Bearer ${token}` }
  });

  if (response.status === 401) {
    // 显示强制下线消息
    ElMessage.error("您的账号已被强制下线，请重新登录");

    // 清除登录状态
    localStorage.clear();
    sessionStorage.clear();

    // 跳转登录页
    setTimeout(() => window.location.href = "/login", 1000);
  }
}
```

### 4.2 响应拦截器处理401

**文件**: `src/utils/request.ts`

```typescript
request.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      // 显示错误消息
      ElMessage.error(error.response.data?.message || "未授权，请重新登录");

      // 清除所有本地存储
      localStorage.clear();
      sessionStorage.clear();

      // 跳转登录页
      setTimeout(() => window.location.href = "/login", 1000);
    }
  }
);
```

## 五、工作流程

```
管理员点击强退
    ↓
① 删除 online_users 记录
② 将 token 加入 token_blacklist
    ↓
被强退用户感知（两种方式）
    ↓
┌─────────────────┬─────────────────┐
│  方式1: 主动请求  │  方式2: 心跳检测  │
│  立即生效         │  最多30秒        │
└─────────────────┴─────────────────┘
    ↓                    ↓
认证中间件检测token在黑名单
    ↓
返回 401 错误
    ↓
前端清除登录状态 → 跳转登录页
```

## 八、技术要点

1. **Token黑名单**: 被强退用户的token无法继续使用
2. **双重检测**: 主动请求检测 + 定时心跳检测
3. **即时生效**: 用户有操作时立即生效
4. **自动清理**: Token过期后自动失效（通过 expires_at > NOW() 过滤）
5. **用户体验**: 友好的错误提示 + 自动跳转

## 九、性能优化

1. **索引优化**: token字段建立索引，加快黑名单查询
2. **定期清理**: 建议添加定时任务清理过期的黑名单记录
3. **心跳间隔**: 30秒间隔平衡实时性和性能

```sql
-- 定期清理过期黑名单（可放在定时任务中）
DELETE FROM token_blacklist WHERE expires_at < NOW();
```
