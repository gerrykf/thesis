## 📖 使用指南

### 1. 数据库部署

```bash
# 1. 创建数据库
mysql -u root -p
CREATE DATABASE health_management CHARACTER SET utf8mb4;

# 2. 导入初始化脚本
mysql -u root -p health_management < 程序实现文档/db/init_database.sql

# 3. 导入菜单数据
mysql -u root -p health_management < 程序实现文档/db/menus-data-from-routes.sql
```

### 2. 后端启动

```bash
cd 程序实现文档/backend/health-backend
npm install
npm run dev
# 运行在 http://localhost:3000
```

### 3. 前端启动

**后台管理端**:
```bash
cd 程序实现文档/frontend/health-manage
pnpm install
pnpm run dev
# 运行在 http://localhost:8848
```

**移动端H5**:
```bash
cd 程序实现文档/frontend/h5-app
pnpm install
pnpm run dev
# 运行在 http://localhost:5173
```

## 🎯 核心亮点

### 技术亮点

1. **前后端分离架构**
   - RESTful API设计
   - JWT Token认证
   - 统一响应格式

   - 3级角色体系

3. **多语言国际化**
   - 前端: vue-i18n

4. **数据可视化**
   - ECharts 图表

5. **性能优化**
